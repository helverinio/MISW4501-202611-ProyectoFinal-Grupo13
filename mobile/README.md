# Mobile Temp Project

A React Native app built with Expo and Expo Router.

# Basic functionality to implement
- Login
- Admin Login?
- Logout
- User registration
- Landing
- Hotel search
- Create reservation
- Cancel reservation
- View reservations
- Push notifications
- Checkin with QR code
- Rate a hotel


## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start the development server:
   ```bash
   npm start
   ```

3. Run on a specific platform:
   ```bash
   npm run android   # Android
   npm run ios       # iOS
   npm run web       # Web
   ```

## Project Structure

```
├── src/              # App routes (Expo Router)
│   ├── _layout.tsx   # Root layout
│   └── index.tsx     # Landing page
├── assets/           # Static assets (images, fonts)

```
