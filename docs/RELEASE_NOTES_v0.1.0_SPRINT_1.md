# Release Notes - v0.1.0 (Sprint 1)

Fecha de publicación: 2026-04-11  
Producto: TravelHub  
Versión global de producto: `v0.1.0`

## Resumen
Esta entrega corresponde al **Sprint 1** del PoC e incluye capacidades base de autenticación, búsqueda, detalle de propiedad, flujo de reserva y cancelación en Web, además de login y búsqueda en App Móvil.

## Alcance funcional entregado

### Web
1. **HU-W-18** - Visualización del detalle de la propiedad.
2. **TFP-15.1 / HU-W-19** - Creación de reservas: carrito de reserva con hold temporal.
3. **HU-W-32** - Login de usuario viajero.
4. **HU-W-13** - Cancelación de una reserva web.
5. **HU-W-19** - Creación de reservas.
6. **HU-W-17** - Búsqueda avanzada de hospedaje.
7. **TFP-15.2 / HU-W-19** - Creación de reservas: confirmación visual y por correo electrónico para la web.

### App Móvil
1. **HU-M-34** - Login de usuario viajero desde la app.
2. **HU-M-26** - Búsqueda de hospedaje desde la app.

## Notas de versionamiento
- Esta release marca la versión de producto **v0.1.0** para Sprint 1.
- Para este sprint, Web y Backend se reportan bajo la versión global del producto.
- La App Móvil puede conservar versionado técnico propio, pero debe mapearse a esta release de producto.
