TravelHub UI

Guia visual para portal web, portal admin y experiencia movil.

Esta pagina consolida los patrones que ya existen en los prototipos: paleta azul, superficies limpias, componentes redondeados, estados claros y continuidad entre desktop y movil.

  • Unificacion de tokens visuales para evitar variaciones entre vistas.
  • Jerarquia tipografica mas clara para titulos, formularios y metricas.
  • Separacion explicita entre componentes web y patrones nativos de movil.
  • Estados de exito, alerta y error con mejor contraste y consistencia.
