Bienvenida

Este manual fue preparado para orientar a usuarios finales en el uso de TravelHub. Su proposito es facilitar la navegacion en la plataforma y reducir dudas durante procesos como busqueda, reserva, seguimiento y administracion operativa.

Proposito del manual

El manual busca:

  • Explicar de forma ordenada como usar cada plataforma.
  • Documentar los flujos principales paso a paso.
  • Servir como material de consulta para universidad, cliente o equipo funcional.
  • Dejar una base clara para completar con capturas de pantalla y validaciones posteriores.

Alcance

La documentacion cubre los procesos funcionales visibles de la plataforma y se enfoca en actividades frecuentes del usuario final. No incluye:

  • Documentacion de APIs.
  • Configuracion tecnica de infraestructura.
  • Procedimientos internos de desarrollo o despliegue.

Plataformas cubiertas

  1. Portal web para clientes.
  2. Aplicacion movil para clientes.
  3. Portal administrativo para hoteles, administradores o partners.

Convenciones del manual

Para mantener consistencia, en este documento se usan las siguientes convenciones:

Convencion Uso
Paso a paso Procedimiento secuencial para completar una tarea
Resultado esperado Resultado que el usuario debe observar al terminar
Nota Aclaracion util antes o despues de una accion
Advertencia Riesgo, restriccion o punto que requiere cuidado
Imagen de apoyo Referencia visual de la pantalla descrita

Requisitos basicos para usar TravelHub

Antes de utilizar la plataforma, se recomienda contar con:

  • Conexion estable a internet.
  • Navegador web actualizado para el portal web.
  • Dispositivo movil compatible para la app.
  • Correo electronico activo para recibir confirmaciones.
  • Datos de viaje, fechas y numero de huespedes.
  • Medio de pago valido, si el flujo lo requiere.
Note

El contenido de este manual se concentra en la experiencia de uso y en las acciones que el usuario realiza dentro de TravelHub.
