TravelHub Manual de Usuario

Bienvenido al manual funcional de TravelHub, la plataforma de reservas hoteleras orientada a clientes, administradores y aliados operativos.

Este sitio fue organizado para servir como guia navegable de uso diario. Cada seccion explica tareas frecuentes con lenguaje claro, pasos concretos y orientacion practica para cada plataforma.

En esta documentacion encontrara

  • Una introduccion general a TravelHub y a sus plataformas.
  • Un manual del portal web para clientes.
  • Un manual de la aplicacion movil para clientes.
  • Un manual del portal administrativo para hoteles, partners o responsables operativos.
  • Una seccion de preguntas frecuentes.
  • Un glosario con terminos clave del proceso de reservas.

Plataformas cubiertas

Plataforma Publico principal Objetivo
Portal web Clientes Buscar hospedajes, reservar, consultar y gestionar reservas
App movil Clientes Realizar reservas y dar seguimiento desde el telefono
Portal administrativo Administradores, hoteles y partners Supervisar reservas, tarifas, ingresos y operacion basica

Alcance del manual

Este manual describe el uso funcional de TravelHub con base en las pantallas revisadas para:

  • Portal Web
  • Movil
  • Admin Portal

La documentacion esta organizada para que el usuario pueda recorrer de forma secuencial los procesos de acceso, busqueda, reserva, seguimiento y administracion operativa.
